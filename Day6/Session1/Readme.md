A simple browser-based web application to add, store, and display HTML, CSS, and JavaScript topics. The project is built using only HTML, CSS, and JavaScript with localStorage for persistence — no backend required.

Category (HTML, CSS, JavaScript)

Name:LearnTech

Description:This project is a browser-only web application designed to help learners and developers organize and review HTML, CSS, and JavaScript concepts. Users can add new topics with details such as category, name, and description, which are then saved in the browser using localStorage.

The saved topics are displayed on a separate page in a card layout, making it easy to browse through different concepts. Each card has a fixed height with a “View More” button, allowing users to expand and read the full description without cluttering the interface.

The app is lightweight, fully responsive, and doesn’t require any backend setup — making it an excellent beginner-friendly project for practicing form handling, DOM manipulation, localStorage, and responsive UI design.

Topics are stored in localStorage and persist even after refreshing.

Display topics on a separate page in cards layout.

Fixed-height cards with a View More button to expand and read the full description.

Responsive design for desktop and mobile screens.

⚙️ How to Run

Clone or download this repository.

Open index.html in your browser.

Add some topics and submit.

Open display.html to view the stored topics.
Run on Google Chrome Browser as I have used local Storage it has limitation with Browser.
